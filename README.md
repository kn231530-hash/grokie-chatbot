# Grokie AI Chatbot v6.0

A beautiful terminal-based AI chatbot with **Message Mode** and **Voice Mode**.

## Features

- Beautiful robot startup screen
- **Message Mode** – Text only chat
- **Voice Mode** – Bot speaks replies (Text-to-Speech)
- Calculator, password generator, games, jokes, facts, quotes and more
- Colored interface

## Requirements

```bash
pip install pyttsx3 colorama
```

## How to Run

```bash
python chatbot.py
```

Then choose:

1. **Message Mode** (text only)
2. **Voice Mode** (bot will speak)

## Commands

Type `help` inside the chatbot to see the full list.

Main commands:
- `hello`, `time`, `date`, `joke`, `fact`, `quote`, `game`, `rps`
- `calculate 25*4`, `password`, `flip`, `dice`
- `mode` / `message` / `voice` to switch modes
- `bye` to exit
